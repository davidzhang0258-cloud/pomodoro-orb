# 番茄钟悬浮球 · Pomodoro Orb

一个 60 像素的番茄悬浮球，常驻在 macOS 桌面最上层。没有 Dock 图标，没有需要管理的窗口 —— 按一个快捷键（默认 Option+L）或点一下圆球，就能拿到专注计时、休息计时，以及带分段记录的正计时。

[English](README.md)

## 为什么还要再做一个番茄钟

因为计时器就该在你不需要它的时候彻底隐身。悬浮球透明、无边框、始终置顶、可跨显示器拖动，还会记住你把它放在哪里。它刻意保持安静 —— 没有提示音、没有系统通知、没有弹窗。

## 功能

- **桌面悬浮球** —— 60×60，无边框透明，在所有桌面（Space）上都置顶，按住即可拖到任意位置（含跨显示器），退出重开还停在原处。
- **专注 / 休息双计时** —— 圆球上有环形进度和颜色徽章；专注时长预设 15 / 25 / 45 / 60 分钟，休息预设 5 / 10 / 15 分钟。
- **带分段记录的正计时** —— 往正方向计时，随时「记一段」，适合给单篇阅读、单项任务掐表；每段结束都会入库。
- **今日统计** —— 今日专注总时长、今日休息总时长，以及今日记录列表（专注 / 休息 / 正计时）。
- **菜单栏常驻** —— 菜单栏 🍅 图标：显示或隐藏悬浮球、移到当前鼠标所在屏幕的右上角、开机自启动开关、退出。
- **全局快捷键** —— 默认 Option+L，可在设置里改。
- **开机自启动** —— 通过当前用户的 LaunchAgent 实现。
- **跟随系统深浅色** —— 自动切换浅色 / 深色主题。
- **数据全部本地** —— 状态存在 `localStorage`，App 不发任何网络请求。

## 环境要求

- macOS（在 Apple Silicon 上开发）
- Node.js 18+
- Electron 33

## 从源码运行

```bash
git clone https://github.com/davidzhang0258-cloud/pomodoro-orb.git
cd pomodoro-orb
npm install
npm start
```

首次 `npm install` 会下载 Electron 二进制（约 100 MB）。

## 使用说明

- 鼠标移到圆球上展开面板；单击圆球固定展开；再单击取消固定。
- 按住圆球拖动即可移动位置，下次启动还在这里。
- 按 Option+L 显示或隐藏悬浮球；快捷键可在 ⚙️ 设置里修改。
- 多显示器：菜单栏 🍅 →「移到当前鼠标所在屏幕右上角」。

## 实现方式

只有两个文件，没有框架、没有构建步骤：

- `main.js` —— Electron 主进程：无边框透明窗口、置顶并显示在所有工作区、轮询全局鼠标坐标实现跨屏拖拽、菜单栏、全局快捷键、LaunchAgent 自启动、单实例锁。
- `index.html` —— 整个界面都在一个文件里：专注 / 休息 / 正计时的状态机、渲染，以及 `localStorage` 持久化。与主进程之间只通过少量 IPC 通道通信。

## 已知限制

- 仅支持 macOS —— 依赖 `app.dock`、LaunchAgent 和多显示器 API。
- 未签名、未公证。想拷到别的机器用请自行打包 `.app`，否则会被 Gatekeeper 拦下。
- 「开机自启动」会写入 `~/Library/LaunchAgents/com.pomodoro.orb.plist`，其中记录的是 App 包路径，所以只对打包好的 `.app` 有意义，`npm start` 方式下不生效。
- 刻意保持安静：没有提示音，也没有系统通知。
